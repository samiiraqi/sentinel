# Security Policy

Sentinel is a solo project, so security support is best effort.

## Supported versions

Only the `main` branch is supported.

## Reporting a vulnerability

Use the **Report a vulnerability** button under this repository's **Security** tab (GitHub private vulnerability reporting).

Please do not open a public issue for a vulnerability.

## Response

Best effort. I aim to acknowledge reports within 7 days.

## Scope

Sentinel is a local, read-only scanner. See [Known limitations](README.md#known-limitations) for what it does and does not cover.
